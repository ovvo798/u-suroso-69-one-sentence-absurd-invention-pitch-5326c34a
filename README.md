An entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on [make.fun](https://make.fun).

`main.py` (Python 3.13, standard library only) writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance to `/output/entry.txt`:

> Meet the Umbrella That Holds a Grudge: a rain umbrella that remembers every time you abandon it on the bus and sulks in the hallway until you apologise to it in writing.

## Run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt`.
